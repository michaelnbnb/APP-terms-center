MediMinder-Pelacak Obat Kebijakan Privasi

Informasi yang Kami Kumpulkan

MediMinder-Pelacak Obat dirancang dengan memperhatikan privasi Anda. Kami hanya menyimpan informasi yang diperlukan untuk menyediakan layanan pengingat obat:

  • Detail obat (nama, jadwal, dosis)
  • Preferensi pengingat

Semua informasi ini disimpan secara lokal hanya di perangkat Anda dan tidak dikirimkan ke server kami.

Analitik Aplikasi

Kami menggunakan layanan Analitik Aplikasi Apple untuk menerima informasi anonim dan agregat tentang penggunaan aplikasi, kinerja, dan crash. Ini membantu kami meningkatkan pengalaman aplikasi tetapi tidak melibatkan pengumpulan data pribadi Anda. Data analitik ini ditangani sesuai dengan Kebijakan Privasi Apple.

Bagaimana Kami Menggunakan Informasi Anda

Informasi Anda digunakan semata-mata untuk:

  • Menyediakan pengingat obat
  • Meningkatkan fungsionalitas aplikasi
  • Dukungan teknis saat Anda menghubungi kami

Penyimpanan Data

Semua data obat Anda disimpan dengan aman dan secara lokal hanya di perangkat Anda. Kami tidak memiliki akses ke data ini, dan data tersebut tidak dikirimkan dari perangkat Anda.

Layanan Pihak Ketiga

Kami menggunakan StoreKit Apple untuk pembelian dalam aplikasi. Layanan ini diatur oleh kebijakan privasi Apple.

Hak Anda

Anda memiliki hak untuk:

  • Mengakses data Anda (melalui antarmuka aplikasi)
  • Menghapus data Anda (dengan menghapus data aplikasi atau aplikasi itu sendiri)
  • Mengekspor data Anda (jika didukung oleh aplikasi)
